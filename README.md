# PYTHON-LAB-EXPERIMENT-2
PYTHON PROGRAMMING LAB EXPERIMENT 

## Aim

To develop a Python program to evaluate a cricket player's batting, bowling, fielding, and overall all-rounder performance based on the player's statistics.

## Algorithm

1.Start

2.Enter the player's details.

3.Calculate the batting strike rate.

4.Calculate the bowling economy rate.

5.Check and display the batting performance.

6.Check and display the bowling performance.

7.Check and display the fielding performance.

8.Decide the player's overall all-rounder performance.

9.Display the final result.

10.Repeat the process for another player.

11.Stop.
